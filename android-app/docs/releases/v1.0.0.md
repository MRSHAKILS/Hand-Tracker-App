# Finger Spark v1.0.0

Initial signed Android preview release. Requires Android 7.0 / API 24 or newer and a camera.

## Download And Install

Download `Finger-Spark-v1.0.0.apk` from the assets below. Open it on the phone and allow installation from your browser or file manager when Android prompts. Grant camera access when choosing Paint or Game.

If an earlier development APK is installed, uninstall it first: debug and release builds have different signing certificates. Uninstalling clears the saved name and language; Android 7-9 app-specific captures are also removed. Gallery captures on Android 10+ are stored separately.

## Included

- Offline, on-device index-fingertip tracking.
- Paint mode with palette selection, clear gesture, and adaptive brush.
- Game mode with target collection and session score.
- Front/rear camera selection, capture, sound control, and Bangla/English UI.
- Camera-session and capture cancellation when leaving play.
