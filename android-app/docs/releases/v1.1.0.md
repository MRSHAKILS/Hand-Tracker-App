# Finger Spark v1.1.0

UI refinement preview for Android 7.0 / API 24 and newer.

## Download

Download `Finger-Spark-v1.1.0.apk` from the release assets. This release uses the
same signing key as v1.0.0 and can update that signed installation without an
uninstall. An earlier debug-signed app still needs to be uninstalled first.

## UI And Interaction Updates

- Illustrated Paint and Game choices with a consistent creative-studio identity.
- Two-column mode choices on regular phones; stacked rows on narrow windows or
  larger text settings.
- A smaller hand/orbit region and centered content width on larger screens.
- Clearer typography, a quieter creator footer, and a contrasting camera toolbar.
- Inline name validation and support for the keyboard Done action.
- One screen-reader button per mode tile, accessible icon labels, and timeout
  handling that allows sufficient time to use camera controls.
- Static artwork and skipped splash when animations are disabled or battery
  saver is active.

The camera, hand tracking, Paint gestures, Game, language switching, capture,
offline permissions, and foreground-only camera lifecycle remain intact.

## Verification And Status

The release build, release lint, and all 23 regression tests pass. Six of these
tests cover responsive layout decisions. APK signing and network-permission
exclusion are verified before publication, and the download includes a SHA-256
checksum.

No authorized phone or configured emulator was available for visual acceptance.
This remains a preview release. Verify Bangla, large text, keyboard behavior,
both camera lenses, and touch interactions on the intended device.
